# Деплой на Fly.io

Мета: щоб застосунок працював 24/7 і накопичував статистику **без вашого ПК**.
Усі файли вже готові (`Dockerfile`, `fly.toml`, env-налаштування). Потрібно
кілька команд від вас — у Fly інакше не можна, ключ прив'язаний до вашого акаунта.

## 0. Один раз: встановити flyctl і залогінитись

Windows PowerShell:
```powershell
iwr https://fly.io/install.ps1 -useb | iex
```
(або macOS/Linux: `curl -L https://fly.io/install.sh | sh`)

Потім:
```powershell
fly auth login      # відкриє браузер; зареєструйтесь/увійдіть
```
> Fly просить прив'язати картку навіть для дрібних машин. Ця конфігурація
> (shared-cpu-1x, 512 МБ, том 1 ГБ, ЄС) коштує приблизно **$3–4/міс**.

## 1. Створити застосунок (з готового fly.toml)

У корені проєкту:
```powershell
fly launch --no-deploy --copy-config --name binancemonitor-ВАШ-СУФІКС --region ams
```
- `--copy-config` — узяти наш `fly.toml`, нічого не перегенеровувати;
- `--no-deploy` — спершу створимо том, потім деплой;
- ім'я має бути унікальним у Fly — додайте свій суфікс (напр. `binancemonitor-dima`).

Якщо `fly launch` спитає щось про Postgres/Redis — відмовляйтесь (не потрібні).

## 2. Створити постійний том під базу

Ім'я тому має збігатися з `fly.toml` (`bmm_data`):
```powershell
fly volumes create bmm_data --region ams --size 1
```

## 3. Задеплоїти

```powershell
fly deploy
```

## 3.5. (Необов'язково) Сповіщення в Telegram

Токен і чат — це секрети, тож задаються через `fly secrets` (не в коді):
```powershell
fly secrets set BMM_TG_TOKEN="123456:AA..." BMM_TG_CHAT="@my_channel"
```
Після цього застосунок перезапуститься сам і почне слати сповіщення для монет
із увімкненим дзвіночком. Як створити бота й дізнатися chat_id — див. README,
розділ «Сповіщення в Telegram».

## 4. Відкрити

```powershell
fly open
```
Або подивитись URL і логи:
```powershell
fly status
fly logs
```

Далі — як локально: у пошуку додаєте символи, вони бекфіляться на 30 днів і
збираються далі. Вотчліст і статистика лежать на томі й переживають перезапуски.

## Корисне

- **Оновити після змін коду:** `git pull` → `fly deploy`.
- **Порахувати з реального символу на сервері:** `fly ssh console -C "python -m app.selfcheck BTCUSDT"`.
- **Резервна копія БД:** `fly ssh console` → файл `/data/monitor.sqlite3`.
- **Приватність:** URL публічний, але дані — лише публічний ринок, секретів немає.
  Якщо схочете сховати за паролем — скажіть, додам простий basic-auth.

## Якщо все ж хочете, щоб деплой зробив я

Технічно я можу виконати `fly deploy`, лише якщо ви створите **обмежений
deploy-токен** і передасте його:
```powershell
fly tokens create deploy -x 999h
```
Але чесно: моє середовище тимчасове й гео-заблоковане (US-IP), тож я не зможу
ні тримати сервіс, ні доглядати його після сесії — на Fly він і так житиме сам.
Тому запуск із вашого боку (кроки 0–4) — надійніший. Токен передавайте лише
якщо усвідомлюєте, що це доступ на деплой у ваш акаунт.
